## Notes

- Tiers: `easy` tasks are one-function fixes in tiny packages; `hard` tasks (`hard-*`) are user reports against one shared app of about 20 modules, with no file or function named.
- 15 tasks is below the 20 to 50 Anthropic suggests for an agent eval, so only large differences between harnesses are detectable; the intervals say how large.
- Solve rate is the mean of per-task solve rates; its interval is a two-stage bootstrap over tasks and then trials (10,000 resamples). pass@3 and pass^3 are the unbiased estimators over tasks with at least 3 trials.
- Tokens are input plus output plus cache tokens per trial, as the harness reports them (`deepagents_ollama` reports no cache tokens). Wall time runs from `run_started` to the end of the run: VM creation and model latency included.
- USD covers every graded trial, failed ones included. Local models cost $0. A run cut off by the run limit reports no usage: its tokens, and for a priced model its cost, count as unknown.
- Infrastructure errors: 0 (re-run); trials lost to them: 0.
